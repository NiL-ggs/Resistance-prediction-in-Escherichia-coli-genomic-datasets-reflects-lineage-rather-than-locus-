# Pre-computed results

Outputs of a complete pipeline run, so tables and figures can be checked without rerunning.

## tables/

| File | Contents |
|---|---|
| `CIP/CTX/CTZ/GEN_association_results_v2.csv` | All 16,435 positions per drug: naive chi-square, p, q, odds ratio, and 10-PC adjusted beta, t, p, q |
| `summary_v2.csv` | Significant counts per drug, naive and 10-PC |
| `pca_variance_explained.csv` | Variance explained by the top 10 components |
| `pc_sensitivity.csv` | λ, significant counts, and rank of position 3,538,947 for 0, 2, 5, 10, 20 and 50 components |
| `homoplasy.csv` | Per position: number of states, minimum changes on the tree, consistency index, variant count |
| `cmh_lineage.csv` | Within-lineage Cochran–Mantel–Haenszel p-values per drug |
| `logistic_top50.csv` | Logistic refit of the top 50 positions per drug: odds ratio, 95 % CI, p |
| `tree.nwk` | Maximum-likelihood phylogeny, Newick, 809 tips |
| `tables.json` | Formatted table data (annotation and effects for the leading positions) |
| `GWAS_supplementary_tables.xlsx` | Supplementary Tables S1–S12 with a README sheet |
| `classifier_comparison.csv`, `prediction_auc.csv`, `perm_summary.csv`, `perm_strongest.csv`, `threshold_cv.csv`, `threshold_perm.csv`, `clonality_diagnostic.csv` | Prediction, permutation-null and lineage-threshold results |

Positions are 1-based coordinates on *E. coli* K-12 MG1655 (NC_000913.3).

## tables/revision/

Results of steps 27–31, added after peer review.

| File | Contents |
|---|---|
| `feature_set_auc.csv` | AUC for SNPs only, principal components only and both, under random and lineage-blocked folds, for 10/20/50 components and two classifiers; `pca_fitted_on` says whether the components were computed within the training fold or from all 809 isolates |
| `feature_set_delta_ci.csv` | Differences between feature sets with 95 % paired bootstrap intervals |
| `encoding_sensitivity.csv` | Classification accuracy under binary, one-hot and integer-code encodings |
| `known_gene_summary.csv` | 27 known resistance genes and regulatory regions: positions present, non-synonymous count, smallest p-value per method |
| `known_gene_positions.csv` | Per-position detail for those genes: alleles, predicted effect, p-values, homoplasy |
| `known_gene_enrichment.csv` | Whether known-gene positions rank above the rest of the genome, per drug and method |
| `candidate_genes.csv` | Mixed-model-significant genes outside the known set, with within-lineage support, lineage concentration and permutation recurrence |
| `candidate_loci.csv` | Per-position detail behind `candidate_genes.csv` |
| `gene_level_null.csv` | Gene-level significance counts against the within-lineage permutation null |
